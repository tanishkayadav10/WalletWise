# 💰 WalletWise

**WalletWise** is an AI-powered personal finance Android application designed to help users manage their money, track expenses, set budgets, and get intelligent financial assistance.

## ✨ Features

* 🔐 User registration and login
* 💸 Add, edit, and delete transactions
* 🎯 Set and manage monthly budgets
* 📊 Visualize spending with charts
* 🧾 Receipt scanning with AI
* 🤖 AI-powered financial assistant
* 👤 User profile management
* 🔥 Firebase Realtime Database integration

## 🛠️ Tech Stack

* **Language:** Java
* **UI:** XML
* **Platform:** Android
* **Database:** Firebase Realtime Database
* **AI:** Google Gemini API
* **Build Tool:** Gradle

## ⚙️ Setup

1. Clone the repository.
2. Open the project in Android Studio.
3. Connect/configure your Firebase project.
4. Add your Gemini API key through `local.properties`.
5. Sync Gradle and run the application.

> **Note:** API keys and local configuration files are not included in this repository.
